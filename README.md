# IDLE PARTY: Desktop Legends (çalışma adı)

Masaüstü widget tarzı idle / auto-battler pixel RPG için Oyun Tasarım Dokümanı (GDD) ve yapay zeka geliştirme yol haritası.

- `docs/IdleParty_GDD.pdf` — tam GDD (PDF)
- `docs/IdleParty_GDD.md` — aynı içerik, yapay zeka ajanlarına vermek için tek dosya Markdown
- `docs/src/*.md` — bölüm kaynak dosyaları (düzenleme buradan yapılır)
- `tools/build_gdd.py` — PDF ve birleşik Markdown'ı yeniden üretir (`pip install reportlab` sonrası `python3 tools/build_gdd.py`)
